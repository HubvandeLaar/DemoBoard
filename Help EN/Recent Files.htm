Recent Files

The Recent Files form consists of two command buttons and a list of recently opened or saved files.

  • New Empty File

    This starts the Main form with an empty file.

  • Open Existing File

    Before opening the Main form, a file dialog is started to select a file from the local PC and start the Main form using this file.

  • List of Recent Files

    Shows the recently opened or saved files. Double clicking starts the Main form using this file.
